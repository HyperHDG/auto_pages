Detailed Description

Forward exceptions thrown in the body of a parallel loop to the calling thread.

An exception that leaves an OpenMP parallel region terminates the program. Therefore, the body of a parallel loop is executed via run, which catches all exceptions. Once an exception has been caught, the remaining iterations are skipped, and rethrow (called after the loop) rethrows the first caught exception. Without OpenMP, this results in the same behavior as a serial loop.
