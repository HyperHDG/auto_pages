Detailed Description

Test problems for the Timoshenko beam solver on networks of straight beams.

From the former reproducibles_python/parameters/timoshenko.hxx (notation of Hauck, Malqvist, Rupp, "Arbitrary order approximations at constant cost for Timoshenko beam network models" (2024), eq. (2.2)): on an edge with unit tangent i, the displacement u, rotation r, stress resultant n and moment m satisfy, with unit coefficients, -(d_x u + i x r) = n, -d_x r = m, d_x n = f, d_x m + i x n = g, with continuity of u, r and balance of n, m at the nodes. The rotation variable phi of the solver is -r, right_hand_side_n is f and right_hand_side_m is -g. The parameter functions receive a point and a direction and return the component of the vector field along it.
