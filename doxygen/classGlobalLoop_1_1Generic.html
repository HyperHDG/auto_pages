Detailed Description

template<class TopologyT, class GeometryT, class NodeDescriptorT, class LocalSolverT, typename dof_value_t = double, typename dof_index_t = unsigned int>
class GlobalLoop::Generic< TopologyT, GeometryT, NodeDescriptorT, LocalSolverT, dof_value_t, dof_index_t >

The single global loop built on local operators.

The loop is a scatter–gather engine over hyperedges. For every hyperedge it gathers the local trace from a global vector, hands it to the hyperedge's local operator, and scatters the result. It never sees block matrices, factorizations, or boundary conditions of the local solver, and it never allocates global vectors: every entry point writes into caller-provided vectors (any type with size() and operator[], e.g. std::vector or std::span).

Local solver protocol (cf. doc/local_operator_design.md):

  • Args: runtime parameters (time, ...) forwarded to every call,
  • local_operator(edge, Kind, args): builds the immutable operator of that kind with apply<k>(solver, edge, in, args, out) and residual(solver, edge, lambda, args, r); what it computes and keeps is the solver's business (e.g. local_solver/local_operator.hxx). The loop hands the solver and the hyperedge to every call of the operator,
  • optional n_operator_slots(edge, Kind, args) and operator_slot(edge, Kind, args): the solver numbers its operators of that kind, and hyperedges with the same number share one,
  • optional Kinds: a std::tuple of the kinds of operators the solver builds (kinds.hxx), if there are others than Stiffness,
  • optional constrained_node<space_dim>(node_type): default predicate for constrain_dirichlet.

Kinds: prepare and the sweeps are templates on the kind of operator, Stiffness by default (loop.apply<Mass>(x, y)); each kind has its own store, prepared on its own.

Store: after prepare the operators live in a contiguous vector until release, one per slot; without operator_slot, the slot of a hyperedge is its index. A slot names the operator that is stored, not the local problem: hyperedges of one slot read the same operator, whose results may still depend on the hyperedge it is applied to. Operators without state (an empty type) are all the same, so there is one slot for all hyperedges. The loop keeps nothing per hyperedge beyond the operators. Without prepare every sweep builds the operator of a hyperedge, uses it and drops it. Every public sweep takes that decision once and runs a branch-free per-edge body for the chosen mode.

Constraints: a sorted index set of global dofs owned by the loop. Constrained dofs are not part of the system (prescribed values are zero in this prototype, Dirichlet data enters via the local load): every sweep reads x as zero there, and apply and residual return zero there. So apply is P J P with the projection P onto the free dofs, symmetric if J is, and singular; assemble gives the same matrix, with a unit diagonal on the constrained dofs on request.

Serial. Parallel sweeps (scatter strategy) are a separate step.

Triplets of J into caller-provided arrays of size n_triplets(identity_rows).

Every hyperedge's block is apply<n_loc> of the identity (so the matrix is the matrix-free operator by construction). Entries in constrained rows and columns are multiplied by zero (branch-free mask), so the matrix is symmetric if J is; with identity_rows a unit diagonal entry is appended for every constrained dof, which makes it non-singular. Duplicate (row, col) pairs have to be summed by the consumer (as scipy's coo_matrix does).
