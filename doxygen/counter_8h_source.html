1/*
2 nanobind/intrusive/counter.h: Intrusive reference counting sample
3 implementation.
4
5 Intrusive reference counting is a simple solution for various lifetime and
6 ownership-related issues that can arise in Python bindings of C++ code. The
7 implementation here represents one of many ways in which intrusive
8 reference counting can be realized and is included for convenience.
9
10 The code in this file is designed to be truly minimal: it depends neither
11 on Python, nanobind, nor the STL. This enables its use in small projects
12 with a 100% optional Python interface.
13
14 Two section of nanobind's documentation discuss intrusive reference
15 counting in general:
16
17 - https://nanobind.readthedocs.io/en/latest/ownership.html
18 - https://nanobind.readthedocs.io/en/latest/ownership_adv.html
19
20 Comments below are specific to this sample implementation.
21
