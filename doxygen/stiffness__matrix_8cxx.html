Detailed Description

Check the assembly of the condensed (stiffness) matrix.

The matrix assembled by trace_to_flux_mat (with the local matrix being computed per hyperedge and with the local matrix being computed only once) is compared to the matrix whose columns are obtained by applying the matrix-free operator trace_to_flux to all unit vectors. This is done

  • for the local solver Diffusion, which provides trace_to_flux_mat (one factorization per hyperedge), on a uniform mesh with mixed boundary conditions, on a uniform mesh with a space dependent diffusion coefficient, on a non-uniform hypergraph, and on a refined hypergraph with hypernodes shared by more than two hyperedges (also after changing the refinement), and
  • for the local solver DiffusionUniform, which does not provide trace_to_flux_mat (fallback).

Moreover, it is checked that

  • using factorize_once for a space dependent diffusion coefficient throws std::invalid_argument (in debug and in release mode), and
  • exceptions of the local solver are forwarded to the caller (also if the assembly is parallelized with OpenMP, where they must not leave the parallel region).
