Detailed Description

Layouts of local operators: what a local solver stores of its condensed local problem.

A local solver of the hybridized kind (Diffusion, ...) describes the local problem of a hyperedge by its blocks (Blocks)

A x = B lambda + l, flux = C x + D lambda,

with the local unknowns x (n_ldofs), the trace lambda (n_loc), and the local load l, which depends on the hyperedge, the time and the data (local_load of the solver). If the leading n_eliminate unknowns form a diagonal block of A (e.g. the flux unknowns of an LDG-H method with an orthonormal basis, affine elements and coefficients constant on the element), the solver says so in the type of its blocks; the factorization then eliminates them explicitly and factorizes the Schur complement of the others only (detail::Factors), in every layout.

A layout makes the operator GlobalLoop::Generic applies: any type with

static auto make(const SolverT& solver, Edge& edge, Kind kind, const Args& args);

returning an operator with apply<k>(solver, edge, in, args, out), residual(solver, edge, lambda, args, r) and optionally local_solution(solver, edge, lambda, args). The layout asks the solver for what it needs (local_blocks(edge, kind, args), and local_load(edge, args) in residual and local_solution); the operator is handed the solver and the hyperedge in every call, so it keeps neither. The solver is templated on its layout and has a default; users can write their own (e.g. single-precision or symmetric storage) without touching the solver.

Provided: Condensed (the default of Diffusion) stores S = C A^-1 B + D and K = C A^-1, so that apply is S lambda and residual is S lambda + K l, without factors; Factored stores the factors of A with B, C, D, as the local problem is set up, and also provides local_solution; Streaming stores nothing and sets up the local problem in every call.

Which hyperedges read the same stored operator is not the layout's business: the solver numbers them (operator_slot, cf. global_loop/generic.hxx), and operators without state, as those of Streaming, are one for all hyperedges.
