Detailed Description

template<unsigned int space_dimT, typename param_float_t = double>
struct TimoshenkoCrossParameters< space_dimT, param_float_t >

Manufactured solution on the cross of beams along the x and the y axis (domains/cross.geo; also the single beam along y of domains/line.geo).

u = cos(pi x) e_z + cos(pi y) e_y and r = -(sin(pi x) e_y + sin(pi y) e_z), zero at the four ends. Beams along x (i = e_x): n = (pi + 1) sin(pi x) e_z, m = pi cos(pi x) e_y, so f = pi (pi + 1) cos(pi x) e_z and g = -(pi^2 + pi + 1) sin(pi x) e_y. Beams along y (i = e_y): n = sin(pi y) (pi e_y + e_x), m = pi cos(pi y) e_z, f = pi cos(pi y) (pi e_y + e_x) and g = -(pi^2 + 1) sin(pi y) e_z. Both beam lines are smooth through the junction, so the junction conditions hold.
