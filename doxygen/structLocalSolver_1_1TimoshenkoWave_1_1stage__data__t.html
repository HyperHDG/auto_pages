template<unsigned int hyEdge_dimT, unsigned int space_dim, unsigned int poly_deg, unsigned int quad_deg, template< unsigned int, typename > typename parametersT = TestTimoWave0, typename lSol_float_t = double, unsigned int n_stages = 1>
struct LocalSolver::TimoshenkoWave< hyEdge_dimT, space_dim, poly_deg, quad_deg, parametersT, lSol_float_t, n_stages >::stage_data_t

Gauss tableau data in the eigenbasis of the Butcher matrix (doc/hdg_gauss.pdf).

Built at construction by Gauss::build_tableau (ported from hoRK's horkirk.c): nodes and weights by Newton on the Legendre polynomial, Butcher A = W V^{-1}, eigendecomposition A = T diag(theta) T^{-1} via zgeev with conjugate-pair enforcement, so only the ceil(s/2) representatives are solved. Per representative l: eigenvalue theta_l (stage shift sigma_l = 1/(theta_l*dt)), load weight omega_l = (T^{-1} 1)_l, data-combination row tinv_l = (T^{-1})_{l,:}, value-form recombination weight w_l = (b^T A^{-1} T)_l and multiplicity mult_l (2 for a conjugate pair). Endpoint update: y+ = affine * y^n + sum_l mult_l * Re(w_l * y_l), affine = 1 - b^T A^{-1} 1 = (-1)^s. s = 1 is the (all-real) implicit midpoint whose trajectory is Crank-Nicolson\'s; s >= 2 has complex representatives, hence the stage scalar type stage_float_t.
