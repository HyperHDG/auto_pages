Detailed Description

template<unsigned int space_dimT, typename param_float_t = double>
struct LocalSolver::TimoschenkoBeamParametersUnitSquare< space_dimT, param_float_t >

Parameters of the Timoshenko beam solver that are set at run time: a network on the unit square under a uniform force, clamped where the node types say.

The node types that are clamped, the force on every beam and the displacements of the corners (0,0), (1,0), (0,1), (1,1) of the unit square are static data, to be set before the system is built. Clamped nodes have zero rotation and the displacement that interpolates those of the corners bilinearly. There is no distributed moment and no analytic solution, so errors() returns the norm of the discrete solution. The functions receive a point and a direction and return the component of the vector field along that direction. Cf. examples/beam_network_nb_jit.py.
