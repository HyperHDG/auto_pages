Detailed Description

Golden records: the record lines a test prints, checked against an expected file.

A record is one line - {key: value, ...}, printed by tests::record with a printf format. At the end, tests::check compares the records with RECORDS_FILE (tests/expected/<ctest name>.yaml, set by tests/CMakeLists.txt for the tests registered with RECORDS):

  • An expected record matches the one printed record that agrees with it in every integer and string key it has (except iterations); floats are compared to rtol, iterations to iterations_rtol |e| + 2. Strings such as the stop reason of CG are exact.
  • An expected record may hold fewer keys than the printed one, and printed records without an expected one are only counted, so a file can pin a part of the output (the seeds from the Cython-era scripts hold {dim, degree, n, error}).
  • With HYPERHDG_RECORD=1 in the environment, check writes the printed records to RECORDS_FILE instead: HYPERHDG_RECORD=1 ctest -R timoshenko re-records a set.
