template<typename T >
NB_NOINLINE std::shared_ptr< T > shared_from_python ( T *  ptr,
handle  h

inlinenoexcept

Create a std::shared_ptr for ptr that owns a reference to the Python object h; if ptr is non-null, then the refcount of h is incremented before creating the shared_ptr and decremented by its deleter.

Usually this is instantiated with T = void, to reduce template bloat. But if the pointee type uses enable_shared_from_this, we instantiate with T = that type, in order to allow its internal weak_ptr to share ownership with the shared_ptr we're creating.

The next two functions are simultaneously marked as 'inline' (to avoid linker errors) and 'NB_NOINLINE' (to avoid them being inlined into every single shared_ptr type_caster, which would enlarge the binding size)
