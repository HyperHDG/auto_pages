Detailed Description

template<unsigned int hyEdge_dimT, unsigned int poly_deg, unsigned int quad_deg, template< unsigned int, typename > typename parametersT = DiffusionParametersDefault, typename lSol_float_t = double, class LayoutT = LocalOperator::Condensed>
class LocalSolver::Diffusion< hyEdge_dimT, poly_deg, quad_deg, parametersT, lSol_float_t, LayoutT >

Local solver diffusion equation on hypergraph.

This class contains the local solver for an isotropic diffusion equation, i.e.,

\[ - \nabla \cdot ( d \nabla u ) = f \quad \text{ in } \Omega, \qquad u = u_\text D \quad \text{ on } \partial \Omega_\text D, \qquad - d \nabla u \cdot \nu = g_\text N \quad \text{ on } \partial \Omega_\text N \]

in a spatial domain \(\Omega \subset \mathbb R^d\). Here, \(d\) is the spatial dimension space_dim, \(\Omega\) is a regular graph (hyEdge_dimT = 1) or hypergraph whose hyperedges are surfaces (hyEdge_dimT = 2) or volumes (hyEdge_dimT = 3) or hypervolumes (in case of hyEdge_dimT > 3). \(f\) and \(d\) are scalars defined in the whole domain, the Dirichlet and Neumann boundary data needs to be defined on their respective hypernodes.

Moreover, this class provides the functions that approximate the condensed mass matrix. By this, it is possible to approximate parabolic problems (in a very bad way) and to find good starting values for the nonlinear eigenvalue problem.

Template Parameters
hyEdge_dimTDimension of a hyperedge, i.e., 1 is for PDEs defined on graphs, 2 is for PDEs defined on surfaces, and 3 is for PDEs defined on volumes.
poly_degThe polynomial degree of test and trial functions.
quad_degThe order of the quadrature rule.
parametersTStruct depending on templates space_dimTP and lSol_float_TP that contains static parameter functions. Defaults to above functions included in DiffusionParametersDefault.
lSol_float_tThe floating point type calculations are executed in. Defaults to double.
LayoutTWhat GlobalLoop::Generic stores of a local problem (local_operator.hxx): LocalOperator::Condensed (default) or Factored, or a layout of one's own.

Assemble local right-hand for the local solver (from volume function coefficients).

Note that we basically follow the lines of

B. Cockburn, J. Gopalakrishnan, and R. Lazarov. Unified hybridization of discontinuous Galerkin, mixed, and continuous Galerkin methods for second order elliptic problems. SIAM Journal on Numerical Analysis, 47(2):1319–1365, 2009

inlinestaticconstexpr

How many leading local unknowns the factorization may eliminate explicitly.

The flux unknowns come first (dim * n_shape_fct_ + i); their block of the local matrix is the mass matrix weighted with the inverse diffusion coefficient, the same for every component. With the orthonormal Legendre basis on affine hyperedges it is diagonal if the coefficient is constant on the hyperedge, which the parameters declare by constant_coefficients (as for operator_slot). Then the factorization eliminates the fluxes and factorizes the Schur complement of the primal unknowns only (LocalOperator::detail::Factors; debug builds check the block is diagonal); otherwise it factorizes the whole local matrix.

inline

Local condensed matrix, i.e., the matrix representation of trace_to_flux.

Column face * n_glob_dofs_per_node() + dof of the returned matrix is the result of trace_to_flux applied to the unit vector that is one for degree of freedom dof of face face (and its rows are ordered analogously). In contrast to calling trace_to_flux for all unit vectors, the local matrix is assembled and LU factorized only once and the factorization is reused for all unit vectors, which results in the same values.

This is a hand-written version of HYPERHDG_LOCAL_TRACE_TO_FLUX_MAT, which the other local solvers use. The macro evaluates the boundary integrals in assemble_rhs_from_lambda, primal_at_boundary, and dual_at_boundary once per local unit vector, whereas they are only evaluated once here. Since Diffusion is the most frequently used local solver, this is worth the duplication: The assembly of the condensed matrix is up to 1.8 times faster than with the macro (measured for hyperedge dimension 3 and polynomial degree 3, the gain grows with the polynomial degree). The matrix must not depend on hyper_edge.data.
