Detailed Description

template<unsigned int n, unsigned int n_eliminate, typename T>
struct LocalOperator::detail::Factors< n, n_eliminate, T >

Factors of the local matrix A, with the diagonal block of the leading n_eliminate unknowns eliminated explicitly.

With A = [D_A, A_DR; A_RD, A_RR] (D_A diagonal, of size n_eliminate), A x = b is x_R = S^-1 (b_R - A_RD D_A^-1 b_D), x_D = D_A^-1 (b_D - A_DR x_R), with the Schur complement S = A_RR - A_RD D_A^-1 A_DR, of which LU factors are kept. Building costs about 2 n_D n_R^2 + 2/3 n_R^3 instead of 2/3 n^3 flops, a solve about 2 n_R^2 + 4 n_D n_R instead of 2 n^2 per right-hand side, and the factors (2 n_D + n_R) n_R + n_D numbers instead of n^2. Debug builds check that D_A is diagonal (up to 100 epsilon of T, relative).
