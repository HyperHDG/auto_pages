Detailed Description

template<unsigned int space_dimT, typename param_float_t = double>
struct LocalSolver::DiffusionEigsWeightedParametersDefault< space_dimT, param_float_t >

Default parameters of the weighted diffusion eigenvalue problem, cf. below.

Faces of node type 1 are Dirichlet faces, and faces of node type 3 carry hypernode mass. Every other face that is not shared by several hyperedges (e.g. node type 2) is a natural boundary.
