Detailed Description

template<typename T>
class ref< T >

RAII scoped reference counting helper class.

ref is a simple RAII wrapper class that encapsulates a pointer to an instance with intrusive reference counting.

It takes care of increasing and decreasing the reference count as needed and deleting the instance when the count reaches zero.

For this to work, compatible functions inc_ref() and dec_ref() must be defined before including this file. Default implementations for subclasses of the type intrusive_base are already provided as part of the file counter.h.
