Detailed Description

template<unsigned int hyEdge_dimT, unsigned int poly_deg, unsigned int quad_deg, template< unsigned int, typename > typename parametersT = DiffusionParametersDefault, typename lSol_float_t = double>
class LocalSolver::DiffusionTensor< hyEdge_dimT, poly_deg, quad_deg, parametersT, lSol_float_t >

LDG-H diffusion with a sum-factorized, matrix-free local operator (fast diagonalization).

The same discretization as Diffusion (same shape functions, quadrature and unknowns, so the same discrete solution), for hyperedges that are boxes (mat_r diagonal, axis-aligned local normals, as UnitCube and the one-dimensional hyperedges of File) and a diffusion coefficient that is constant on each hyperedge (the parameters declare constant_coefficients). Then the local problem splits into one-dimensional matrices:

  • the flux unknowns q_d have the mass k |E| I (k the inverse diffusion coefficient, the Legendre basis orthonormal) and are eliminated, q_d = (b_q + G_d u) / (k |E|);
  • the Schur complement in u is S_u = sum_d X_d acting in direction d (identity in the others), X_d = tau |F_d| sum_s b_s b_s^T + H_d G_d / (k |E|) with the 1D derivative matrix G_d, its partner H_d = -G_d + boundary terms (= G_d^T up to quadrature) and the endpoint values b_s;
  • S_u^-1 is applied by fast diagonalization: X_d = V_d Lambda_d V_d^T, transform with V_d^T direction by direction, divide by sum_d Lambda_d, transform back with V_d;
  • B and C (trace to volume and back) are extensions and restrictions along one direction. One application costs about 4 d (p+1)^(d+1) + O(d (p+1)^d) operations and the operator stores O(d (p+1)^2) numbers, against (2 d (p+1)^(d-1))^2 for the condensed matrix of Diffusion; nothing is factorized, and no LAPACK is needed.

The load, the errors and the Dirichlet nodes are Diffusion's (composition: a Diffusion member). The local operator implements apply, residual and local_solution for GlobalLoop::Generic; the legacy interface of the other global loops is not provided.
