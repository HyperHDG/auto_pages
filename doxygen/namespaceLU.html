Detailed Description

LU factorization with partial pivoting for any scalar type.

factorize, solve_factored and solve call LAPACK (Wrapper) if it has the scalar type (float, double, std::complex<double>), and the generic implementations below otherwise, e.g. for long double or std::float128_t. The generic ones follow LAPACK's conventions (getrf, getrs, gesv): column-major matrices, 1-based pivots, Wrapper::LAPACKexception for a singular matrix.
