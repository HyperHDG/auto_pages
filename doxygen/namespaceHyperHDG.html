Detailed Description

Python interface for HyperHDG library.

This package is the main ingredient to use the HyperHDG library within Python scripts. Its function import compiles the necessary components just-in-time and provides the as classes that can be used within Python. To this end, the Cython package is heavily used.

Authors
Guido Kanschat, Heidelberg University, 2021.
Andreas Rupp, Heidelberg University, 2021.
