◆ discard_as_unraisable() [2/2]

void python_error::discard_as_unraisable ( handle  context)
inlinenoexcept

Pass the error to Python's sys.unraisablehook, which prints a traceback to sys.stderr by default but may be overridden. The context should be some object whose repr() helps clarify where the error occurred. Like .restore(), this consumes the error and you should not reraise the exception in C++ afterward.
