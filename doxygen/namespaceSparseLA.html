Detailed Description

A namespace containing different functions that implement basic linear algebra operations using large vectors.

This namespace provides several functions to implement basic linear algebra operations of (long) vector type in combination with a class providing a function matrix_vector_multiply. This is mainly used for C++ examples and test cases that do not use the Python interface and its version of an CG method, for example.

Authors
Guido Kanschat, Heidelberg University, 2020.
Andreas Rupp, Heidelberg University, 2020.

Conjugate gradients for A x = b with A symmetric and definite (either sign).

The operator is any callable apply(in, out) that writes out = A in; in and out are std::vector of the value type of b, e.g. [&](const auto& in, auto& out) { loop.apply(in, out); } for GlobalLoop::Generic. b and x are vector-like (size(), operator[]); x is the initial guess on entry (r_0 = b is used without a product if x is zero) and the last iterate on return, also if the solver did not converge.

Parameters
applyThe operator: apply(in, out) sets out = A in.
bRight-hand side.
xInitial guess on entry, solution on return.
optionsStopping criteria and an optional monitor.
Return values
resultStop reason, iterations and residual norms.

Execute conjugate gradient algorithm to find solution to system of equations (legacy).

The interface of the older C++ tests and examples, on top of cg: the template class ProblemT implements trace_to_flux, which takes a large vector and returns the matrix vector product. The associated matrix is assumed to be square and symmetric positive definite.
