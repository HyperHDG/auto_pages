◆ HYPERHDG_LOCAL_TRACE_TO_FLUX_MAT

#define HYPERHDG_LOCAL_TRACE_TO_FLUX_MAT (   loc_mat_expr)

Define member function trace_to_flux_mat of a local solver.

The defined function returns the local condensed matrix, i.e., the matrix representation of trace_to_flux: Column face * n_glob_dofs_per_node() + dof is the result of trace_to_flux applied to the unit vector that is one for degree of freedom dof of face face (and its rows are ordered analogously). The local matrix is assembled and LU factorized only once, and the factorization is reused for all unit vectors. The results are the same as the ones of calling trace_to_flux for all unit vectors.

The macro is to be used within the class definition of a local solver that provides

  • hyEdge_dimT, lSol_float_t, n_loc_dofs_, and n_glob_dofs_per_node(),
  • assemble_rhs_from_lambda(lambda_values, hyper_edge) returning a SmallVec,
  • flux_from_coeffs(lambda_values_in, coeffs, lambda_values_out, hyper_edge), which evaluates trace_to_flux for given local solution coeffs (the solution of the local problem), and whose trace_to_flux solves the local problem with the matrix loc_mat_expr (which may use hyper_edge and time).

The local condensed matrix may only depend on the hyperedge's geometry and node descriptor, the local solver's parameters, and time, but not on the data stored at the hyperedge (hyper_edge.data), just like trace_to_flux.

assemble_rhs_from_lambda and flux_from_coeffs are called for every local unit vector, and usually evaluate boundary integrals in every call. For local solvers whose local matrix is cheap compared to these integrals, a hand-written trace_to_flux_mat that evaluates the integrals only once can be considerably faster (cf. Diffusion::trace_to_flux_mat).
