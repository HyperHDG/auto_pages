Write a domain as a .geo.h5 file (cf. namespace HDF5Domain for the format).

An existing file is overwritten. With vtkhdf (default), the file also contains the VTKHDF view for ParaView, which exists for hyperedge dimensions 1 to 3 in up to 3 space dimensions and is skipped otherwise.
