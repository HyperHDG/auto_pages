Detailed Description

template<unsigned int space_dimT, typename param_float_t = double>
struct LocalSolver::TimoschenkoBeamParametersDefault< space_dimT, param_float_t >

Default parameters of the Timoshenko beam solver: a uniform force -e_z on every beam, no distributed moment, zero displacement and rotation at all Dirichlet nodes.

There is no closed-form solution to this problem, so analytic_result_u and analytic_result_phi are zero and errors() returns the norm of the discrete solution. Convergence studies use their own parameters, cf. reproducibles_python/parameters/timoshenko.hxx. The functions receive a point and a direction and return the component of the vector field along that direction.

Authors
Guido Kanschat, Heidelberg University, 2019–2020.
Andreas Rupp, Heidelberg University, 2019–2020.
