Caster for Eigen::Ref<T>

Compared to the Eigen::Map<T> type caster above, the reference caster accepts a wider set of inputs when it is used in constant reference mode (i.e., Eigen::Ref<const T>). In this case, it performs stride conversions (except for unusual non-contiguous strides) as well as conversions of the underlying scalar type (if implicit conversions are enabled).

For non-constant references, the caster matches that of Eigen::Map<T> and requires an input with the expected layout (so that changes can propagate to the caller).
