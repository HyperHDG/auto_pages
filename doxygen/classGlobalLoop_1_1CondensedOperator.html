Assembly of the condensed matrix of a global loop.

Base class (CRTP) of the linear global loops. The global loop GlobalLoopT, which is passed as a template together with its template arguments, has to declare this class a friend, and to provide the members hyper_graph_ and local_solver_. Passing the template (instead of the class) allows to derive via CondensedOperator<GlobalLoop, TopologyT, ...> without spelling out the derived class.

Assemble the condensed matrix.

Function that assembles the condensed matrix \(A\) of the HDG method, i.e., the matrix of the linear map evaluated by trace_to_flux, in coordinate (triplet) format. Entries with the same row and column index have to be summed up (as done by SciPy's csr_matrix).

If the local solver provides trace_to_flux_mat, its local matrix is factorized once per hyperedge. Otherwise, the local problem is solved for every local unit vector.

Template Parameters
hyNode_index_tTypename of the hypernode index. Defaults to unsigned int.
paramTType of the parameter (passed through to the local solver).
Parameters
paramParameter of trace_to_flux, i.e., the time at which given analytic functions will be evaluated (or the shift for eigenvalue problems).
factorize_onceIf true, the local matrix is only computed (and factorized) once for every combination of face types (boundary conditions) and reused for all hyperedges. This is only correct if all hyperedges have the same local matrix, e.g., for uniform meshes with coefficients that are constant in space. It is wrong for space dependent diffusion tensors or non-uniform meshes, which is detected for a sample of hyperedges (for all hyperedges in debug mode) and results in an exception. Defaults to false (local matrix per hyperedge).
Return values
sparse_matCondensed matrix in coordinate format.
