Assemble the condensed matrix in coordinate (triplet) format.

The local condensed matrix of each hyperedge is obtained at once (cf. for_each_local_matrix for details and the meaning of factorize_once), and its entries are stored column by column (and hyperedge by hyperedge). Entries with the same row and column index have to be summed up (as done by SciPy's csr_matrix). Every hyperedge writes its own block of triplets, so the result does not depend on the number of OpenMP threads.

Compute the local condensed matrix of every hyperedge and hand it to sink.

For every hyperedge edge, sink(edge, hyNodes, loc_mat) is called, where hyNodes are the indices of the hypernodes of the hyperedge and loc_mat points to the local condensed matrix (cf. local_condensed_matrix for its layout).

If factorize_once is true, the local matrix is only computed once for every combination of face (hypernode) types, i.e., for every combination of boundary conditions, and reused for all other hyperedges with the same face types. This is only correct if all these hyperedges have the same local matrix, e.g. for uniform meshes with constant (in space) coefficients. It is wrong if, for example, the diffusion tensor is space dependent or the hyperedges differ in size or shape. Therefore, the local matrices of some hyperedges (the last one of every combination of face types and up to 16 hyperedges evenly spread over all hyperedges, at most one per 32 hyperedges) are recomputed and compared to the reused ones, and an std::invalid_argument is thrown if they differ. This costs at most one local matrix per combination of face types plus 16. If the code is compiled without NDEBUG, this check is done for every hyperedge (which is as expensive as factorize_once being false).

The local matrices are computed in parallel if HyperHDG is compiled with OpenMP. Then, sink is called concurrently for different hyperedges. Exceptions thrown by the local solvers are forwarded to the caller.

Local condensed matrix of a hyperedge, i.e., the matrix representation of trace_to_flux.

If the local solver provides trace_to_flux_mat(hyper_edge, time), which returns the local condensed matrix as a SmallSquareMat, this function is used. Local solvers can implement it by factorizing their local matrix once and reusing the factorization for all unit vectors (cf. local_solver/trace_to_flux_mat.hxx). Otherwise, the local condensed matrix is obtained by applying trace_to_flux to all local unit vectors.

Parameters
local_solverThe local solver.
hyper_edgeThe hyperedge.
timeParameter of trace_to_flux (time or shift). It is passed through to the local solver, so it may also be of a non-scalar type.
loc_matArray of \(n^2\) entries that is filled with the local matrix in column-major order, i.e., entry (row, col) is loc_mat[col * n + row].
