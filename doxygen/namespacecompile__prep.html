compile_prep.compile_commands (   python_class,
  opt 
)

Generate shell commands from CMAKE parameters.

The commands do not change the working directory themselves, since a leading "cd dir;" is not understood by the Windows shell. Instead, all paths are relative to main_dir() and the commands are supposed to be executed by run_command.
